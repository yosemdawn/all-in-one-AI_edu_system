### 前端接口设计
- **系统配置**：
    - 页面：`settings.html` (或集成到主页)
    - 元素：API Key输入框, Secret Key输入框, 保存按钮
    - 交互：保存按钮点击后，将密钥保存到浏览器 `localStorage`。
- **标准答案管理**：
    - 页面：`answers.html` (或集成到主页)
    - 元素：题号输入框, 答案输入框, 题型选择 (单选/填空), 添加按钮, 答案列表展示, 编辑/删除按钮
    - 交互：添加/编辑/删除答案，并实时更新 `localStorage`。
- **答题卡处理与评分**：
    - 页面：`upload.html` (或集成到主页)
    - 元素：文件上传区域 (支持拖拽和点击选择), 上传按钮
    - 交互：选择文件后，点击上传按钮，调用后端 `/api/process` 接口。
- **成绩展示与导出**：
    - 页面：`results.html` (或集成到主页)
    - 元素：学生成绩列表 (包含总分和每题详情), 导出CSV按钮
    - 交互：展示 `/api/process` 返回的结果，点击导出按钮调用后端 `/api/export` 接口。



### 后端接口设计
- **`POST /api/process`**
    - **请求**：`form-data`，包含 `files` (多张图片文件) 和可选的 `doubaoApiKey`, `doubaoSecretKey`。
    - **响应**：JSON数组，每个元素包含 `filename` 和 `parsed` (学生姓名、答案) 或 `error` 信息。
- **`GET /api/grade`** (或 `/api/results`)
    - **请求**：可能包含查询参数，用于筛选或排序。
    - **响应**：JSON数组，包含每位学生的评分结果（总分、每题得分详情）。
- **`GET /api/export`**
    - **请求**：可能包含查询参数，用于指定导出范围。
    - **响应**：CSV文件，包含所有学生的成绩报告。

### 豆包LLM的Prompt设计
- **目标**：从答题卡图片中提取学生姓名和答案。
- **关键信息**：
    - 学生姓名 (`name`)
    - 题目答案 (`answers`): 键为题号（字符串），值为学生答案（字符串）。
- **Prompt示例**：
```
你是一个智能批改助手，请从我提供的答题卡图片中识别学生信息和作答内容。请严格按照以下JSON格式输出结果，不要包含任何额外信息或解释。如果无法识别，请在error字段中说明原因。

JSON格式要求：
{
  "name": "学生的姓名",
  "answers": {
    "1": "第1题的答案",
    "2": "第2题的答案",
    "...": "..."
  }
}

请注意：
1. 提取的姓名应是图片中清晰可见的学生姓名。
2. 答案应是学生在答题卡上填写的对应题号的答案。对于选择题，通常是单个大写字母；对于填空题，是具体的文本内容。
3. 如果图片中没有找到有效的姓名或答案，请在相应的字段中留空或返回错误信息。
```
