# 教师工具箱深度整合说明

## 入口

教师端菜单：教师工具箱

- 客观题批分
- 批量作文检查
- 工具批改记录

## 与作业记录的同步规则

创建工具任务时可以选择“关联作业”。选择后，任务完成时会尝试把每个识别成功、且匹配到班级学生的结果同步到原系统的 `submissions` 记录中。

同步后，教师可以在对应作业详情里看到学生提交状态、AI 分数和 AI 评价；学生也可以在自己的作业结果页看到这次工具批改结果。

默认同步策略是保守的：

- 没有匹配到学生：跳过同步。
- 没有关联作业：只保留工具任务记录，不写入作业提交。
- 学生没有提交记录：创建一条 `ai_reviewed` 提交记录。
- 学生已有草稿：更新为正式提交并写入 AI 批改结果。
- 学生已有正式提交：默认跳过，避免覆盖学生原始提交。
- 教师已批改：永远跳过，不会覆盖教师最终批改。
- 勾选“覆盖已有学生提交”后：可以覆盖已有正式提交的 AI 结果，但仍不会覆盖教师已批改记录。

## 导出

工具批改记录支持 CSV 导出。导出内容包含：

- 文件名、学生姓名、学号
- 关联作业
- 匹配状态
- 分数/总分
- 任务状态
- 同步状态
- 提交记录 ID
- 错误信息或总评

导出使用登录态请求，不再通过新窗口直接打开接口，避免鉴权失败。

## 部署配置

后端需要配置豆包多模态模型：

- `DOUBAO_API_KEY`
- `DOUBAO_BASE_URL`，默认 `https://ark.cn-beijing.volces.com/api/v3`
- `DOUBAO_MODEL`，默认 `doubao-seed-2-0-lite-260215`

如果配置 `REDIS_URL`，教师工具任务会进入 BullMQ 队列处理；没有 Redis 时会在当前后端进程内异步处理。

上传图片会保存到后端工作目录下的 `uploads/teacher-tools`。

## 验收建议

1. 创建一个已发布作业，并关联一个含学生的班级。
2. 用教师账号进入教师工具箱，选择该班级和作业。
3. 上传清晰图片创建任务。
4. 等任务完成后查看工具批改记录，确认同步状态为“已创建”或“已更新”。
5. 进入该作业详情，确认对应学生出现提交记录和 AI 分数。
6. 用学生账号进入该作业，确认可以看到同步后的批改结果。
