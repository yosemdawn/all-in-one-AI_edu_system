# AI 作业批改系统使用说明书与功能介绍

## 一、系统概述

AI 作业批改系统是一套面向学校、培训机构和教师个人使用的 Web 教学辅助平台。系统围绕“班级管理、作业发布、学生提交、AI 批改、教师复核、学习结果查看”建立完整闭环，帮助教师减少重复批改工作，同时保留人工审核和教学反馈空间。

系统支持三类角色：

- 管理员：负责用户、角色、菜单、AI 模型和系统基础配置。
- 教师：负责班级管理、作业发布、AI 规则配置、作业批改、批量工具批改。
- 学生：负责加入班级、查看作业、提交作业、查看批改结果。

系统核心流程如下：

1. 管理员创建或导入用户，并配置 AI 模型。
2. 教师创建班级并添加学生。
3. 教师创建 AI 批改规则。
4. 教师发布作业到指定班级。
5. 学生在线提交作业。
6. AI 自动批改并生成分数和评价。
7. 教师查看 AI 结果并进行人工复核。
8. 学生查看最终批改结果和改进建议。

除常规在线作业流程外，系统还集成“教师工具箱”，支持客观题答题卡批分和批量作文图片检查，并可将线下批改结果同步回原有作业记录。

## 二、主要功能模块

### 1. 统一登录与权限系统

系统提供统一登录入口，登录后会根据用户角色进入对应工作台。

支持能力：

- 管理员、教师、学生多角色登录。
- JWT 登录认证。
- 动态菜单权限控制。
- 首次登录强制修改密码。
- 登录状态失效后自动跳转登录页。
- 不同角色只能访问自己有权限的功能。

### 2. 管理员端

管理员端用于维护系统基础数据和运行配置。

主要功能包括：

- 系统概览
- 用户管理
- 角色管理
- 菜单管理
- AI 模型配置
- 权限分配
- 系统数据查看

### 3. 教师端

教师端是系统的核心业务入口。

主要功能包括：

- 教学中心
- 班级管理
- 作业管理
- AI 规则管理
- 批改中心
- 教师工具箱

### 4. 学生端

学生端用于学生完成学习任务和查看反馈。

主要功能包括：

- 学习中心
- 我的班级
- 我的作业
- 作业详情
- 作业提交
- 批改结果查看

## 三、管理员使用说明

### 1. 系统概览

管理员登录后可进入系统概览页面，查看平台整体运行情况。

常见统计内容包括：

- 用户数量
- 教师数量
- 学生数量
- 班级数量
- 作业数量
- 提交数量
- 批改状态分布

该页面用于快速了解系统使用情况和教学数据概况。

### 2. 用户管理

用户管理用于维护系统账号。

支持操作：

- 新增用户
- 编辑用户信息
- 查看用户详情
- 重置用户密码
- 批量导入用户
- 批量删除用户
- 按角色、状态等条件筛选用户

用户角色通常包括：

- 超级管理员
- 教师
- 学生

学生账号建议维护学号信息，便于班级成员管理和教师工具箱自动匹配。

### 3. 角色管理

角色管理用于控制不同角色拥有的权限范围。

支持操作：

- 创建角色
- 编辑角色
- 启用或停用角色
- 给角色分配菜单
- 给角色分配权限

系统默认包含管理员、教师、学生等基础角色。

### 4. 菜单管理

菜单管理用于维护系统左侧导航和动态路由。

支持操作：

- 新增菜单
- 编辑菜单名称、路径、图标、排序
- 设置菜单父子关系
- 隐藏详情页菜单
- 为角色分配可见菜单

菜单配置会影响用户登录后看到的功能入口。

### 5. AI 模型配置

AI 模型配置用于维护系统调用的大模型信息。

常见配置项：

- 模型名称
- 模型编码
- 服务商
- API Key
- Base URL
- 模型 ID
- 启用状态

AI 作业批改和教师工具箱中的识别、评分、作文检查都依赖模型配置。若模型 API Key 缺失或不可用，AI 批改任务会失败。

## 四、教师使用说明

### 1. 教学中心

教师登录后默认进入教学中心。教学中心用于展示教师个人教学数据概览。

通常包括：

- 班级数量
- 作业数量
- 学生提交情况
- 待批改数量
- 最近作业
- 批改进度

教师可以通过教学中心快速进入班级、作业和批改相关页面。

### 2. 班级管理

班级管理用于创建和维护教师自己的班级。

支持操作：

- 创建班级
- 编辑班级信息
- 查看班级详情
- 管理班级学生
- 批量添加学生
- 移除学生
- 查看班级作业
- 查看班级学生提交情况

班级是作业发布和学生提交的基础。教师发布作业时，需要选择一个或多个班级。

### 3. 添加学生

教师可以在班级详情中添加学生。

常见方式：

- 手动添加学生
- 批量导入学生
- 学生通过班级邀请码加入

建议学生信息包含：

- 姓名
- 学号
- 登录账号
- 所属班级

学号越规范，后续批改统计和工具箱图片识别匹配越准确。

### 4. AI 规则管理

AI 规则用于定义 AI 批改作业时的评价标准和提示词。

支持配置：

- 规则名称
- 适用学科或场景
- 评分标准
- 批改提示词
- 评价维度
- 是否启用

教师发布作业时可以选择 AI 规则。AI 会根据作业内容、参考答案、评分要求和规则提示词生成批改结果。

### 5. 作业管理

作业管理用于创建、编辑、发布和查看作业。

创建作业时通常需要填写：

- 作业标题
- 作业描述
- 发布班级
- 开始时间
- 截止时间
- 作业原题
- 参考答案
- 教师补充批改要求
- 提交形式
- 是否允许附件
- AI 批改规则

作业状态包括：

| 状态 | 说明 |
| --- | --- |
| 草稿 | 作业尚未发布，学生不可提交 |
| 发布中 | 学生可以查看并提交 |
| 已终止 | 作业已停止，学生不可继续提交 |

### 6. 作业详情

作业详情用于查看某个作业的整体完成情况。

教师可以查看：

- 作业基本信息
- 发布班级
- 应交学生数
- 已提交数量
- 待批改数量
- AI 已批改数量
- 教师已批改数量
- 学生提交列表

提交列表支持按班级、学生姓名、学号、提交状态和批改状态筛选。

### 7. 批改中心

批改中心用于集中查看和处理学生提交。

教师可以：

- 查看待批改作业
- 查看学生提交内容
- 查看 AI 批改结果
- 人工调整分数
- 编写教师评语
- 提交最终批改

AI 结果用于辅助教师判断，教师最终批改优先级最高。教师提交人工批改后，学生端会看到教师分数和教师评语。

### 8. 教师工具箱

教师工具箱用于处理线下图片类批改任务，目前包含：

- 客观题批分
- 批量作文检查
- 工具批改记录

工具箱既可以独立使用，也可以与系统作业记录打通。

#### 客观题批分

适用于周测、单元测试、选择题、填空题等固定答案题型。

使用流程：

1. 进入教师工具箱 -> 客观题批分。
2. 填写任务名称。
3. 选择班级。
4. 可选：选择关联作业。
5. 上传学生答题卡图片。
6. 输入标准答案说明。
7. 点击 AI 解析答案。
8. 输入分值规则。
9. 点击 AI 解析分值。
10. 创建批分任务。
11. 等待系统识别和评分。
12. 查看结果或导出 CSV。

系统会尝试识别：

- 学生姓名
- 学号
- 每题答案
- 每题对错
- 总分

#### 批量作文检查

适用于作文、短文写作等图片形式的批改任务。

使用流程：

1. 进入教师工具箱 -> 批量作文检查。
2. 填写任务名称。
3. 选择班级。
4. 可选：选择关联作业。
5. 输入作文要求，或上传作文题目图片。
6. 上传学生作文图片。
7. 创建作文检查任务。
8. 等待系统识别和批改。
9. 查看分数、总评和修改建议。

系统会生成：

- 作文识别文本
- 分数
- 优点
- 问题
- 修改建议
- 总评
- 学生匹配状态

#### 工具批改记录

工具批改记录用于查看工具任务历史。

可查看：

- 任务名称
- 任务类型
- 关联班级
- 关联作业
- 任务状态
- 处理进度
- 成功数量
- 失败数量
- 同步数量
- 任务详情

可执行：

- 查看详情
- 导出 CSV
- 取消处理中任务

## 五、学生使用说明

### 1. 学习中心

学生登录后进入学习中心，可以查看自己的学习任务和提交概况。

常见内容包括：

- 我的班级
- 待完成作业
- 已提交作业
- 已批改作业
- 最近反馈

### 2. 我的班级

学生可以查看自己已加入的班级。

如果学生未加入任何班级，系统会引导学生先加入班级。

学生加入班级后，才能查看该班级下发布的作业。

### 3. 我的作业

我的作业用于查看教师发布给学生所在班级的作业。

学生可以查看：

- 作业标题
- 教师名称
- 截止时间
- 作业状态
- 是否已提交
- 是否已批改

### 4. 提交作业

学生进入作业详情后可以提交作业。

支持内容：

- 富文本答案
- 图片或附件
- 草稿保存
- 正式提交

提交后，系统会根据配置进入 AI 批改流程。AI 批改完成后，学生可以看到 AI 分数和反馈。

### 5. 查看批改结果

学生可以在提交详情中查看：

- 自己提交的内容
- AI 批改分数
- AI 评价内容
- AI 批改状态
- 教师最终分数
- 教师评语

如果教师已人工批改，教师批改结果作为最终反馈展示。

## 六、作业批改闭环说明

系统的核心闭环如下：

```text
教师创建班级
  -> 添加学生
  -> 创建 AI 规则
  -> 发布作业
  -> 学生提交
  -> AI 自动批改
  -> 教师复核
  -> 学生查看结果
```

在这个流程中：

- 班级决定作业发布范围。
- 作业决定学生提交入口。
- AI 规则决定 AI 批改标准。
- 学生提交触发 AI 批改。
- 教师复核形成最终评价。
- 学生端沉淀历史作业和批改反馈。

## 七、教师工具箱与作业记录同步规则

当教师在工具箱任务中选择“关联作业”，并勾选“同步到学生提交记录”后，系统会尝试把工具批改结果写入原有作业提交记录。

同步规则如下：

| 场景 | 系统行为 |
| --- | --- |
| 未关联作业 | 只保存工具记录，不写入作业提交 |
| 未匹配到学生 | 跳过同步 |
| 匹配到多个同名学生 | 跳过同步 |
| 学生没有提交记录 | 创建一条 AI 已批改提交记录 |
| 学生已有草稿 | 更新为正式提交，并写入 AI 批改结果 |
| 学生已有正式提交 | 默认跳过，避免覆盖学生原始提交 |
| 勾选覆盖已有学生提交 | 覆盖已有正式提交的 AI 结果 |
| 教师已批改 | 永远跳过，不覆盖教师最终批改 |

同步成功后：

- 教师可以在作业详情中看到该学生提交记录。
- 教师可以查看工具箱生成的 AI 批改结果。
- 学生可以在自己的作业结果页看到同步后的批改结果。

## 九、常见问题

### 1. 学生为什么看不到作业？

可能原因：

- 学生未加入对应班级。
- 作业仍是草稿状态。
- 作业没有发布到学生所在班级。
- 作业已终止。
- 学生账号权限异常。

### 2. AI 为什么没有批改？

可能原因：

- AI 模型未配置。
- API Key 不可用。
- 后端队列服务不可用。
- 作业没有配置 AI 规则。
- 学生提交内容为空或格式异常。

### 3. 教师工具箱为什么没有同步到作业？

可能原因：

- 没有关联作业。
- 没有勾选同步到学生提交记录。
- 未识别到学生姓名或学号。
- 识别出的学生不属于所选班级。
- 同名学生导致匹配不明确。
- 学生已有正式提交且未勾选覆盖。
- 教师已批改，系统不会覆盖。

### 4. 学生提交后还能修改吗？

系统支持提交次数限制。若作业已被教师批改，通常不允许再次提交。具体规则以当前系统配置和页面提示为准。

### 5. 教师批改和 AI 批改哪个优先？

教师批改优先级最高。AI 批改结果用于辅助判断，教师可以人工复核、调整分数并填写最终评语。

## 十、部署与配置说明

### 1. 基础环境

系统主要技术栈：

- 前端：Vue 3 + TypeScript + Vite + Element Plus
- 后端：NestJS + TypeScript
- 数据库：MongoDB
- 队列：Redis + BullMQ，可选但生产建议配置
- AI：支持豆包等大模型接口

### 2. 常用环境变量

后端常见配置：

```env
PORT=3000
MONGODB_URI=mongodb://127.0.0.1:27017/nengdou-ai
JWT_SECRET=请替换为高强度密钥
CORS_ORIGINS=http://localhost:5173
```

AI 相关配置：

```env
DOUBAO_API_KEY=你的豆包APIKey
DOUBAO_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
DOUBAO_MODEL=doubao-seed-2-0-lite-260215
```

队列配置：

```env
REDIS_URL=redis://127.0.0.1:6379
```

如果未配置 Redis，部分任务会在当前后端进程内异步处理。生产环境建议配置 Redis。

### 3. 上传文件目录

教师工具箱上传图片默认保存到：

```text
uploads/teacher-tools
```

生产部署时需确保后端进程对上传目录有写入权限。

## 十二、功能边界与注意事项

- AI 批改结果仅作为辅助，关键成绩建议教师复核。
- 教师最终批改不会被工具箱同步结果覆盖。
- 教师工具箱依赖图片质量，图片模糊、倾斜、遮挡会影响识别准确率。
- 学生信息中的姓名和学号越规范，工具箱自动匹配越准确。
- 生产环境应配置稳定的 MongoDB、Redis 和 AI 模型 API Key。
- 管理员应定期检查用户权限和 AI 模型可用状态。
