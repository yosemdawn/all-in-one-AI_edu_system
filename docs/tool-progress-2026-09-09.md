# 判分与批量作文进度优化

两个工具页及批改记录详情统一显示当前阶段、当前图片、已处理/总张数、成功和失败数量、耗时。后台在识别要求、识别答题卡、计算分数、批阅作文和保存结果之前持久化阶段信息，首张尚未完成时也有明确反馈。百分比按实际处理完的图片数计算，不估算 AI 的内部完成比例。

工具页每次请求结束后等待约 3 秒再更新；记录页约 5 秒刷新。慢请求不会重叠，临时错误会退避重试；离开页面或切换任务会取消旧请求并忽略迟到响应。后台轮询错误在进度区提示，避免反复弹出网络错误。完成、失败、取消后停止该任务轮询。

新建任务将任务 ID 保留在页面地址中，刷新后继续跟踪；从菜单重新进入时加载最近一次该类型任务。记录页打开的处理中任务详情也会自动更新。

同时保留同名但不同路径图片的独立结果，并防止取消后迟到的 AI 错误把任务重新显示为失败。

验证：新增 8 个测试（3 个真实隔离 MongoDB 接口测试、4 个轮询/百分比测试、1 个实际 Vue 组件渲染测试）。累计后端单元 24、端到端 38、前端测试 10 个全部通过；前后端构建通过。未调用真实 AI、未部署或推送本次改动。已有构建告警和历史 lint 问题未在本次展开处理。
