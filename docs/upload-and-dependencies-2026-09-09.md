# 上传保护与依赖更新（2026-09-09）

对应上线审查第 10、14 项。保留两个批阅工具原有流程，只增加上传提示和提交前校验，没有增加配置页面。

## 图片上传

- 支持 JPG、PNG、WebP。每张最多 15 MiB，每次图片合计最多 40 MiB；答题卡/作文各最多 100 张，作文题目最多 5 张，题目和作文共用总大小限制。
- 前端选择时拦截不支持或超限的文件，提交时再次检查。超过总大小时提示减少图片、分两次上传；本次没有引入自动拆单或压缩，避免改变批阅记录和文字清晰度。
- API 边接收边写入临时文件，统计实际接收字节，适用于没有 Content-Length 的请求。Multer 同时限制字段数量、字段大小、嵌套深度和数组索引。网关保持 50 MiB 整包上限，给表单字段及 multipart 边界留出空间。
- 除声明的 MIME 类型外，还检查文件签名、真实图像元数据及尺寸；最多 4000 万像素，不接受动画多帧。图像正文损坏仍可能在 AI 识别时失败，这不是完整逐像素解码校验。
- 单个后端进程最多同时处理 4 次上传，每个教师同时 1 次；每个教师已记录的任务图片默认上限 2 GiB。磁盘可用空间不足约 416 MiB 时停止接收新图片。约束集中在 `ToolUploadService`，不增加教师设置项；多实例扩容前应改用共享配额/锁及共享存储。
- 上传中断、验证失败及预览结束后立即清理临时文件；每小时及启动时清理超过 24 小时的遗留临时文件和旧版预览文件。数据库明确拒绝保存时清理复制的图片；数据库写入结果不确定时先查任务，保留无法确认的原图，避免删掉已保存任务的文件。
- 已有任务的原图不按时间自动删除。进程在复制文件后、保存任务前退出，或数据库长期断连时，可能留下需要管理员核对的原图；底层磁盘保护继续生效。存储配额按任务记录统计，不能替代磁盘监控。达到配额后需要管理员整理保留策略，不能直接删除仍被任务引用的文件。
- 保留中文原始文件名，避免当前批阅图片的名称乱码。Nginx 读取响应超时改为 120 秒，覆盖最长 90 秒的作文要求识别。

## 依赖

- Axios 更新到 1.20.0；ECharts 更新到 6.1.0。
- SheetJS 从公共 npm 的 0.18.5 切换到官方发行包 0.20.3，锁文件记录 URL 和完整性校验。依据：[SheetJS 官方安装说明](https://docs.sheetjs.com/docs/getting-started/installation/nodejs/)。
- NestJS common/core/platform-express/testing 统一到 11.2.3，Mongoose 更新到 9.9.5，并补齐查询条件的类型约束。其他受影响传递依赖在锁文件内更新。
- Multer 使用 2.3.0；NestJS 当前仍固定引用旧版 Multer，因此用同一主版本的 override 统一修补。新增的 Sharp 0.35.4 只用于后端图像检查。
- `npm audit --omit=dev`：前端、后端均为 **0 条**。后端包含开发依赖的完整审计也是 0 条。
- 前端完整审计仍有 **6 条开发工具链告警（1 高、5 中）**，涉及 Vite/esbuild、旧 Vue 类型检查工具等。生产镜像运行 Nginx 静态文件，不运行 Vite；开发工具链的大版本迁移另行处理。本次没有忽略或屏蔽这些告警。
