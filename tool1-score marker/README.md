# 智能批分助手

一个简单易用的答题卡自动批阅工具。

老师们只需要把答题卡录入一下，再传一下学生答题卡，，点批阅

喝一杯茶

然后成绩就都出来啦

！需要注意一下：答题卡要求字迹清晰，然后要清楚地写“姓名：xxx” LLM才能识别人名

然后这套系统目前只支持客观题（选择题和填空题 还有一切固定的答案）

如果需要批量作文批阅欢迎大家看我主页另一个程序 essay-grader！！这个也是我的心血之作！！

欢迎各位大神pull request or issue

## 🚀 快速启动

### 方法1：双击启动（推荐）
1. 双击 `start.bat` 文件
2. 等待编译完成
3. 在浏览器中访问：`http://localhost:3000`

### 方法2：手动启动
```bash
cd backend
npm run build
npm start
```
然后在浏览器中访问：`http://localhost:3000`

## 📖 使用说明

1. **系统配置**：点击"系统配置"，输入豆包LLM API Key
2. **标准答案管理**：添加试题的标准答案
3. **答题卡处理**：上传答题卡图片进行自动批阅
4. **成绩展示**：查看批阅结果并导出CSV

## 🔧 技术栈

- 前端：HTML + CSS + JavaScript
- 后端：Node.js + Express + TypeScript
- AI：豆包LLM

## 📝 注意事项

- 需要配置豆包LLM API Key才能使用批阅功能
- 支持JPG和PNG格式的答题卡图片
- 所有数据保存在本地，不上传到第三方服务器
