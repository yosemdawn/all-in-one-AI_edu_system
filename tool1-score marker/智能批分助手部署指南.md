# 智能批分助手部署指南

本项目旨在为教育工作者提供一个高效、自动化的答题卡批量批阅工具。本指南将帮助您在本地环境中部署和运行该项目。

## 1. 项目结构

项目包含 `frontend` 和 `backend` 两个主要目录：

- `frontend/`: 包含前端静态文件 (HTML, CSS, JavaScript)。
- `backend/`: 包含后端 Node.js (TypeScript) 服务。

## 2. 部署步骤

### 2.1 前提条件

确保您的系统已安装以下软件：

- Node.js (推荐 v18 或更高版本)
- npm (Node.js 包管理器)

### 2.2 后端部署

1.  **进入后端目录**：
    ```bash
    cd smart-grader/backend
    ```

2.  **安装依赖**：
    ```bash
    npm install
    ```

3.  **编译 TypeScript 代码**：
    ```bash
    npm run build
    ```

4.  **配置豆包LLM API Key** (可选，但强烈推荐)
    您可以通过两种方式提供豆包LLM的API Key：
    - **环境变量**：在启动后端服务前，设置 `DOUBAO_API_KEY` 环境变量。
      例如：
      ```bash
      export DOUBAO_API_KEY="您的API Key"
      npm start
      ```
    - **前端传入**：在前端界面的“系统配置”页面输入并保存。如果前端传入了密钥，将优先使用前端传入的密钥。
    
    **注意**：豆包LLM的Secret Key现在是可选的，如果您的API Key不需要Secret Key，可以留空。

5.  **启动后端服务**：
    ```bash
    npm start
    ```
    后端服务将默认运行在 `http://localhost:3000`。

### 2.3 前端部署

前端是静态文件，可以直接通过浏览器访问。由于后端服务运行在 `http://localhost:3000`，前端在本地运行时需要确保能够访问到该地址。

1.  **进入前端目录**：
    ```bash
    cd smart-grader/frontend
    ```

2.  **直接打开 `index.html`**：
    您可以使用任何现代浏览器直接打开 `frontend/index.html` 文件。由于浏览器安全策略，直接打开 `file://` 协议的页面可能无法直接与 `http://localhost:3000` 的后端进行通信。推荐使用以下方式：

    - **使用一个简单的HTTP服务器**：
      如果您安装了 Python，可以在 `frontend` 目录下运行一个简单的HTTP服务器：
      ```bash
      python -m http.server 8000
      ```
      然后通过浏览器访问 `http://localhost:8000`。

    - **通过本项目提供的部署链接访问**：
      本项目已将前端部署至一个临时公共链接，您可以直接访问该链接进行测试和使用。

## 3. 使用说明

1.  **系统配置**：
    - 访问前端页面后，点击导航栏的“系统配置”。
    - 输入您的豆包LLM API Key，Secret Key可以根据需要选择性输入，点击“保存配置”。这些密钥将保存在您的浏览器本地存储中。

2.  **标准答案管理**：
    - 点击导航栏的“标准答案管理”。
    - 输入题号、标准答案和题型（单项选择题或填空题），点击“添加/更新答案”。
    - 您可以查看、编辑和删除已录入的答案。标准答案将保存在您的浏览器本地存储中。

3.  **答题卡处理**：
    - 点击导航栏的“答题卡处理”。
    - 将答题卡图片（JPG或PNG格式）拖放到指定区域，或点击区域选择文件。
    - 选择文件后，点击“开始批阅”。系统将上传图片到后端，后端调用豆包LLM进行识别和评分。

4.  **成绩展示**：
    - 批阅完成后，系统会自动跳转或您可以点击导航栏的“成绩展示”。
    - 页面将显示每位学生的总分和每道题的得分详情。
    - 您可以点击“展开/收起”查看每道题的详细批阅结果。

5.  **导出CSV**：
    - 在“成绩展示”页面，点击“导出CSV”按钮。
    - 系统将生成一个包含所有学生成绩的CSV文件，并自动下载。该文件采用UTF-8 with BOM编码，可直接用Excel打开。

## 4. 注意事项

- **豆包LLM API Key**：请妥善保管您的API密钥，不要泄露给他人。
- **数据隐私**：本项目支持本地化运行，所有数据处理均在您的本地环境进行，不会上传到第三方服务器（豆包LLM除外）。
- **评分规则**：选择题和填空题均采用严格匹配规则。请确保标准答案的准确性。
- **错误处理**：如果LLM无法识别图片内容或返回格式不正确，系统会显示相应的错误信息。

感谢您使用智能批分助手！
